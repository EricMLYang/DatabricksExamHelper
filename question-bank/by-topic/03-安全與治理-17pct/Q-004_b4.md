## 題目內容
### 題幹
<!-- ⚠️ 保持英文原文，不要翻譯 -->
Which of the following describes the minimal permissions a data engineer needs to modify permissions of an existing cluster?
### 選項
<!-- ⚠️ 保持英文原文，不要翻譯 -->
- **A.** "Can Restart" privilege on the cluster
- **B.** "Can Manage" privilege on the cluster
- **C.** Cluster creation allowed + "Can Restart" privileges on the cluster
- **D.** Cluster creation allowed + "Can Manage" privileges on the cluster

# 題目解析

---

## 📍 考點識別
**核心技術:** Cluster permissions 權限分級
**關鍵概念:** 修改權限需要 Can Manage
**題目關鍵字：**
- **modify permissions**: 修改權限設定
- **existing cluster**: 既有叢集

---

## ✅ 正解說明
### 為什麼 B 是正確答案？
要修改既有叢集的權限，必須具備該叢集的**Can Manage** 權限。Can Restart 只允許重啟，無權限管理功能；「允許建立叢集」是帳戶層級權限，與修改既有叢集權限無直接關係。

---

## ❌ 錯誤選項排除
### A. Can Restart
**為什麼錯誤？**
- 只能重啟叢集，無法管理或調整權限。

### C. 允許建立 + Can Restart
**為什麼錯誤？**
- 建立叢集權限與修改既有叢集權限無關，仍缺少 Can Manage。

### D. 允許建立 + Can Manage
**為什麼錯誤？**
- Can Manage 已足夠，題目問最小權限，因此不需要額外的建立叢集權限。

---

## 🧠 記憶法
### 口訣
**「改權限要管理，重啟只是重啟。」**

### 比較表
| 權限 | 可做事 |
|---|---|
| Can Attach To | 只能連上叢集 |
| Can Restart | 可重啟 |
| Can Manage | 可設定、可改權限 |
