<!-- ⚠️ 保持英文原文，不要翻譯 -->
Which of the following describes the minimal permissions a data engineer needs to view the metrics and Spark UI of an existing cluster?
### 選項
<!-- ⚠️ 保持英文原文，不要翻譯 -->
- **A.** Cluster creation allowed + "Can Attach To" privileges on the cluster

- **D.** "Can Restart" privilege on the cluster

# 題目解析

---

## 📍 考點識別
**核心技術:** Cluster 權限分級
**關鍵概念:** 查看 Spark UI 需要 Can Attach To
**題目關鍵字：**
- **view metrics and Spark UI**: 只需最低可附加權限
- **existing cluster**: 叢集層級權限

---

## ✅ 正解說明
### 為什麼 C 是正確答案？
查看 Spark UI 與 metrics 只需要能「附加」到叢集，因此 **Can Attach To** 就足夠。更高的 Can Restart / Can Manage 不是最低權限。

---

## ❌ 錯誤選項排除
### A
**為什麼錯誤？**
- 建立叢集權限與查看既有叢集 UI 無關。

### B / D
**為什麼錯誤？**
- 這些是更高權限，不符合「最低權限」。
