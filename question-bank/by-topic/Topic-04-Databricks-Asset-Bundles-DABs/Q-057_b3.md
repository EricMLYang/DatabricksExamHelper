## 題目內容
### 題幹
<!-- ⚠️ 保持英文原文，不要翻譯 -->
A data engineer has an existing Databricks job and wants to manage it using Databricks Asset Bundles. They want to use the Databricks CLI to get the YAML definition of the job and download its referenced artifacts.

Which of the following commands allows the data engineer to achieve this?

### 選項
<!-- ⚠️ 保持英文原文，不要翻譯 -->
- **A.** databricks bundle clone job --existing-job-id
- **B.** databricks bundle get job --existing-job-id
- **C.** databricks bundle download job --existing-job-id
- **D.** databricks bundle generate job --existing-job-id

## ✅ 正解說明
### 為什麼 D 是正確答案？

**`databricks bundle generate` 命令用於從現有資源生成 bundle 設定**：
- 生成 YAML 定義檔
- 自動下載相關的 artifacts（如 notebooks）
- 將現有資源轉換為可管理的 bundle

#### bundle generate 功能
```
databricks bundle generate 功能：
├── 生成 YAML 設定檔
│   └── 包含 job 的完整定義
├── 下載相關 artifacts
│   └── 例如：notebooks、Python 檔案
└── 支援多種資源類型
    └── job, pipeline, app, dashboard
```

#### 使用範例
```bash
# 從現有 job 生成 bundle 設定
databricks bundle generate job --existing-job-id 12345

# 產生結果：
# - resources/jobs/my_job.yml  (YAML 定義)
# - src/notebook.py            (下載的 notebook)
```

## ❌ 錯誤選項排除

### A. databricks bundle clone
**為什麼錯誤？**
- **`clone` 不是有效的 bundle 子命令**
- 不存在於 Databricks CLI 中

### B. databricks bundle get
**為什麼錯誤？**
- **`get` 不是有效的 bundle 子命令**
- 正確的命令是 `generate`

### C. databricks bundle download
**為什麼錯誤？**
- **`download` 不是有效的 bundle 子命令**
- `generate` 才會同時生成定義和下載 artifacts
