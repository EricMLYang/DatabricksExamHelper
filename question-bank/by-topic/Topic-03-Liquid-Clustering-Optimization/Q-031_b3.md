## ✅ 正解說明
### 為什麼 A 和 E 是正確答案？

**Automatic Liquid Clustering 需要兩個先決條件**：
1. **Unity Catalog Managed Table**（不支援 External Table）
2. **Predictive Optimization 已啟用**

#### 先決條件關係圖
```
Automatic Liquid Clustering 需求：
┌─────────────────────────────────────┐
│    Unity Catalog Managed Table      │ ✅ 必須
│    (非 External Table)              │
├─────────────────────────────────────┤
│    Predictive Optimization 啟用     │ ✅ 必須
│    (提供存取模式分析)               │
└─────────────────────────────────────┘
         ↓
┌─────────────────────────────────────┐
│   Automatic Liquid Clustering       │
│   自動優化資料佈局                  │
└─────────────────────────────────────┘
```

#### 為什麼需要 Managed Table？
```
Managed Table 優勢：
├── 完整的 metadata 控制
├── 可追蹤資料存取模式
├── 支援自動維護操作
└── External Table 目前不支援
```

#### 為什麼需要 Predictive Optimization？
```
Predictive Optimization 提供：
├── 分析查詢模式
├── 預測最佳化時機
├── 自動決定 Clustering Keys
└── 智慧化資料佈局
```

#### 啟用方式
```sql
-- 1. 確保是 Unity Catalog Managed Table
CREATE TABLE catalog.schema.my_table (...)
-- 注意：沒有 LOCATION 子句 = Managed Table

-- 2. 啟用 Predictive Optimization
ALTER TABLE catalog.schema.my_table
SET TBLPROPERTIES ('delta.enablePredictiveOptimization' = 'true');

-- 3. 啟用 Liquid Clustering
ALTER TABLE catalog.schema.my_table
CLUSTER BY (column1, column2);
```

## ❌ 錯誤選項排除

### B. Table must be partitioned by a date column
**為什麼錯誤？**
- **Liquid Clustering 是 Partition 的替代方案**
- 不需要預先分區
- 反而建議在新表上用 Liquid Clustering 取代 Partition

```
Liquid Clustering vs Partition：
├── Liquid Clustering → 不需要預先分區
├── Partition → 傳統分區方式
└── 兩者是替代關係，不是依賴關係
```

### C. Table must be a Unity Catalog-external table
**為什麼錯誤？**
- **External Table 目前不支援 Automatic Liquid Clustering**
- 必須是 Managed Table
- 這是選項 A 的相反

### D. Table must have deletion vectors enabled
**為什麼錯誤？**
- **Deletion Vectors 不是 Automatic Liquid Clustering 的先決條件**
- 雖然 Deletion Vectors 可以提升效能
- 但不是必要條件

```
Deletion Vectors：
├── 用途 → 加速 DELETE/UPDATE 操作
├── 與 Liquid Clustering → 無直接關係
└── 不是先決條件
```

## 🧠 記憶法
### 口訣
**「自動 Liquid 要兩條：Managed 表加預測優」**

### Automatic Liquid Clustering 總覽
| 項目 | 說明 |
|------|------|
| 需要 Managed Table | ✅ 必須 |
| 需要 Predictive Opt | ✅ 必須 |
| 需要 Partition | ❌ 不需要 |
| 需要 Deletion Vectors | ❌ 不需要 |
| 支援 External Table | ❌ 不支援 |

### Liquid Clustering 類型比較
| 類型 | 觸發方式 | 先決條件 |
|------|----------|----------|
| Manual | 手動執行 OPTIMIZE | 無特殊要求 |
| Automatic | 系統自動執行 | Managed Table + Predictive Opt |

### 相關功能關係
```
Delta Lake 優化功能：
├── Liquid Clustering → 資料佈局優化
├── Predictive Optimization → 智慧化維護
├── Deletion Vectors → 加速 DML
└── Auto Optimize → 自動檔案壓縮
```
