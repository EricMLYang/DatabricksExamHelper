# 題目解析

---

## 📍 考點識別
**核心技術:** Auto Optimize
**關鍵概念:** 自動壓縮、小檔案問題
**題目關鍵字：**
- **automatically compacts**: 自動壓縮
- **two complementary operations**: 兩個互補操作
- **individual writes**: 個別寫入時

---

## ✅ 正解說明
### 為什麼 B 是正確答案？

**Auto Optimize 包含兩個互補操作**：
- Optimized Writes：優化寫入檔案大小
- Auto Compaction：自動壓縮小檔案

#### Auto Optimize 組成
```
Auto Optimize = Optimized Writes + Auto Compaction

┌─────────────────────────────────────┐
│        Auto Optimize                │
├─────────────────┬───────────────────┤
│ Optimized Writes│ Auto Compaction   │
│ (寫入時優化)    │ (寫入後壓縮)      │
├─────────────────┼───────────────────┤
│ 嘗試寫出 128MB  │ 檢查並壓縮小檔案  │
│ 的檔案          │ 目標也是 128MB    │
└─────────────────┴───────────────────┘
```

#### 運作流程
```
Auto Optimize 運作流程：
寫入資料
    │
    ▼
Optimized Writes
├── 嘗試將輸出檔案大小優化到 128MB
└── 減少產生的小檔案數量
    │
    ▼
Auto Compaction（寫入後檢查）
├── 檢查是否有小檔案可以合併
├── 如果有，執行 OPTIMIZE
└── 目標檔案大小 128MB（非標準的 1GB）
```

---

## ❌ 錯誤選項排除

### A. OPTIMIZE operation
**為什麼錯誤？**
- **OPTIMIZE 是手動執行的命令**
- 不是自動在寫入時執行
- 目標檔案大小是 1GB（不是 128MB）

### C. Auto compaction
**為什麼錯誤？**
- **Auto compaction 只是 Auto Optimize 的一部分**
- 題目說的是「兩個互補操作」
- Auto compaction 只是其中之一

### D. Optimized writes
**為什麼錯誤？**
- **Optimized writes 也只是 Auto Optimize 的一部分**
- 同樣只是兩個操作之一
- 不包含自動壓縮功能

---

## 🧠 記憶法
### 口訣
**「Auto Optimize 有兩招：Optimized Writes 加 Auto Compaction」**

### 功能比較
| 功能 | 類型 | 檔案大小目標 | 觸發時機 |
|------|------|-------------|----------|
| OPTIMIZE | 手動 | 1GB | 主動執行 |
| Auto Optimize | 自動 | 128MB | 寫入時 |
| Optimized Writes | 自動（部分） | 128MB | 寫入時 |
| Auto Compaction | 自動（部分） | 128MB | 寫入後 |
