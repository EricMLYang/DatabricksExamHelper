# 題目解析

---

## 📍 考點識別
**核心技術:** Cluster init scripts 儲存位置
**關鍵概念:** DBFS root 不再支援
**題目關鍵字：**
- **init scripts**: 叢集啟動腳本
- **source locations**: 可用來源路徑

---

## ✅ 正解說明
### 為什麼 C 是正確答案？
Databricks 已不再支援將 init scripts 存放在 **DBFS root**。目前建議使用 **Workspace files、Cloud storage 或 Volumes**。

---

## ❌ 錯誤選項排除
### A / B / D
**為什麼錯誤？**
- 這些仍是官方支援的 init script 來源位置。
