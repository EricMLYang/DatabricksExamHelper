# 題目解析

---

## 📍 考點識別
**核心技術:** Databricks notebook 檔案格式辨識
**關鍵概念:** `# Databricks notebook source` 標記
**題目關鍵字：**
- **establishes a Python file as a notebook**: 轉為 notebook 的識別註記

---

## ✅ 正解說明
### 為什麼 B 是正確答案？
Databricks 以 `# Databricks notebook source` 作為檔案是 notebook 的辨識註記。當檔案回匯入 Databricks 時，系統會依此判斷為 notebook。

---

## ❌ 錯誤選項排除
### A
**為什麼錯誤？**
- `dbutils.notebook` 無法決定檔案型態。

### C
**為什麼錯誤？**
- 建立 SparkSession 與 notebook 格式無關。

### D
**為什麼錯誤？**
- 沒有 `%databricks` 這個 magic command。
