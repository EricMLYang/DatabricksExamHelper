## 題目內容
### 題幹
<!-- ⚠️ 保持英文原文，不要翻譯 -->
Given the following query on the Delta table customers on which Change Data Feed is enabled:

```python
spark.read
    .option("readChangeFeed", "true")
    .option("startingVersion", 0)
    .table("customers")
    .filter(col("_change_type").isin(["update_postimage"]))
.write
    .mode("overwrite")
    .table("customers_updates")
```

Which statement describes the results of this query each time it is executed?

### 選項
<!-- ⚠️ 保持英文原文，不要翻譯 -->
- **A.** Newly updated records will be appended to the target table.
- **B.** Newly updated records will overwrite the target table.
- **C.** The entire history of updated records will be appended to the target table at each execution, which leads to duplicate entries.
- **D.** The entire history of updated records will overwrite the target table at each execution.

# 題目解析

---

## 📍 考點識別
**核心技術:** Change Data Feed (CDF)
**關鍵概念:** spark.read vs spark.readStream、overwrite mode
**題目關鍵字：**
- **spark.read**: 批次讀取
- **startingVersion: 0**: 從版本 0 開始
- **mode("overwrite")**: 覆蓋模式

---

## ✅ 正解說明
### 為什麼 D 是正確答案？

**spark.read 是批次讀取，會讀取完整歷史**：
- `spark.read` 是靜態（batch）讀取
- `startingVersion: 0` 表示從頭開始讀
- 每次執行都讀取從版本 0 到最新的所有變更
- `mode("overwrite")` 覆蓋目標表

#### 執行行為分析
```
每次執行的行為：
1. spark.read 讀取 CDF
   └── 從 version 0 到最新的所有變更

2. filter update_postimage
   └── 過濾出所有更新後的記錄

3. write mode("overwrite")
   └── 完全覆蓋目標表

結果：每次執行，完整歷史覆蓋目標表
```

#### 對比 readStream
```
spark.read（批次）：
├── 每次執行讀取完整範圍
├── startingVersion 是固定起點
└── 適合一次性處理

spark.readStream（串流）：
├── 記住處理進度（checkpoint）
├── 只處理新的變更
└── 適合增量處理
```

---

## ❌ 錯誤選項排除

### A. 新更新記錄會 append
**為什麼錯誤？**
- **寫入模式是 overwrite，不是 append**
- 而且 spark.read 每次都讀完整歷史

### B. 新更新記錄會 overwrite
**為什麼錯誤？**
- **不是「新」更新記錄**
- spark.read + startingVersion: 0 會讀取所有歷史

### C. 完整歷史會 append，導致重複
**為什麼錯誤？**
- **寫入模式是 overwrite，不是 append**
- 如果是 append 才會有重複問題

---

## 🧠 記憶法
### 口訣
**「spark.read 讀全量，overwrite 蓋全表」**

### 讀取方式比較
| 特性 | spark.read | spark.readStream |
|------|-----------|------------------|
| 類型 | 批次 | 串流 |
| 每次範圍 | 完整指定範圍 | 只有新變更 |
| 進度追蹤 | 無 | checkpoint |
| 適用場景 | 一次性處理 | 持續增量 |
