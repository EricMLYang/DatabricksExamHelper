## 題目內容
### 題幹
<!-- ⚠️ 保持英文原文，不要翻譯 -->
The data engineering team is using the LOCATION keyword for every new Delta Lake table created in the Lakehouse.

Which of the following describes the purpose of using the LOCATION keyword in this case ?
### 選項
<!-- ⚠️ 保持英文原文，不要翻譯 -->
- **A.** The LOCATION keyword is used to set a default schema and checkpoint location for the created Delta Lake tables.
- **B.** The LOCATION keyword is used to configure the created Delta Lake tables as external tables.
- **C.** The LOCATION keyword is used to configure the created Delta Lake tables as managed tables.
- **D.** The LOCATION keyword is used to define the created Delta Lake tables in an external database.

# 題目解析

---

## 📍 考點識別
**核心技術:** Delta Lake 表類型（Managed vs External）
**關鍵概念:** CREATE TABLE 的 LOCATION 子句意義
**題目關鍵字：**
- **LOCATION keyword**: 指定外部儲存路徑
- **Delta Lake tables**: 建立表格型態

---

## ✅ 正解說明
### 為什麼 B 是正確答案？
在 Databricks 中，**使用 LOCATION 建立表格表示資料儲存在使用者指定的外部路徑**，因此此表是 **External (Unmanaged) Table**。這也是 LOCATION 子句最核心的用途。

---

## ❌ 錯誤選項排除
### A. 設定 default schema 與 checkpoint
**為什麼錯誤？**
- LOCATION 只定義表資料的儲存路徑，與 schema 或 streaming checkpoint 無關。

### C. 配置為 managed tables
**為什麼錯誤？**
- **沒有 LOCATION** 才會是 managed table；有 LOCATION 則是 external table。

### D. 定義在 external database
**為什麼錯誤？**
- LOCATION 與資料庫層級無直接關係，這是表層級的儲存位置設定。

---

## 🧠 記憶法
### 口訣
**「有 LOCATION 就外部，無 LOCATION 就管理。」**

### 比較表
| 建表方式 | 表類型 | 資料位置 |
|---|---|---|
| 無 LOCATION | Managed Table | 系統管理位置 |
| 有 LOCATION | External Table | 使用者指定路徑 |
