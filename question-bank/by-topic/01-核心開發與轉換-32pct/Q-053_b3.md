## 題目內容
### 題幹
<!-- ⚠️ 保持英文原文，不要翻譯 -->
Which of the following commands allows data engineers to perform an insert-only merge?

### 選項
<!-- ⚠️ 保持英文原文，不要翻譯 -->
- **A.**
```sql
MERGE INTO orders
USING new_orders
ON orders.orders_id = new_orders.orders_id
WHEN NOT MATCHED
    INSERT *
WHEN MATCHED
    IGNORE *
```
- **B.**
```sql
MERGE INTO orders
USING new_orders
ON orders.orders_id = new_orders.orders_id
WHEN MATCHED
    INSERT *
```
- **C.**
```sql
MERGE INTO orders
USING new_orders
ON orders.orders_id = new_orders.orders_id
WHEN NOT MATCHED
    INSERT *
```
- **D.**
```sql
MERGE INTO orders
USING new_orders
ON orders.orders_id = new_orders.orders_id
WHEN MATCHED
    INSERT *
WHEN NOT MATCHED
    IGNORE *
```

# 題目解析

---

## 📍 考點識別
**核心技術:** MERGE INTO 語法
**關鍵概念:** Insert-only merge
**題目關鍵字：**
- **insert-only merge**: 僅插入合併
- **WHEN NOT MATCHED**: 當不匹配時
- **INSERT ***: 插入所有欄位

---

## ✅ 正解說明
### 為什麼 C 是正確答案？

**Insert-only merge 只需要 `WHEN NOT MATCHED` 子句**：
- 只處理不匹配的記錄（新記錄）
- 匹配的記錄（已存在）自動被忽略
- 不需要額外的 WHEN MATCHED 子句

#### Insert-only Merge 語法
```sql
MERGE INTO target_table
USING source_table
ON merge_condition
WHEN NOT MATCHED
    INSERT *
```

#### 行為說明
```
Insert-only Merge 行為：
source_id | target_id | 結果
----------|-----------|------
1         | 1         | 忽略（已存在）
2         | 2         | 忽略（已存在）
3         | (無)      | 插入（新記錄）
4         | (無)      | 插入（新記錄）
```

---

## ❌ 錯誤選項排除

### A. WHEN MATCHED IGNORE *
**為什麼錯誤？**
- **`IGNORE *` 不是有效的 MERGE 語法**
- Delta Lake 不支援 IGNORE 關鍵字

### B. WHEN MATCHED INSERT *
**為什麼錯誤？**
- **邏輯錯誤**
- WHEN MATCHED 用於已存在的記錄
- 不能對已存在的記錄執行 INSERT

### D. WHEN MATCHED INSERT + WHEN NOT MATCHED IGNORE
**為什麼錯誤？**
- **語法和邏輯都錯誤**
- INSERT 不能用於 WHEN MATCHED
- IGNORE 不是有效語法

---

## 🧠 記憶法
### 口訣
**「只插入用 NOT MATCHED，MATCHED 不寫就忽略」**

### MERGE 子句用途
| 子句 | 用途 | 常見操作 |
|------|------|----------|
| WHEN MATCHED | 已存在記錄 | UPDATE, DELETE |
| WHEN NOT MATCHED | 新記錄 | INSERT |
