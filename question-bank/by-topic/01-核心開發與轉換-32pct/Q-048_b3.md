## 題目內容
### 題幹
<!-- ⚠️ 保持英文原文，不要翻譯 -->
A data engineer has been asked to develop a nightly batch job for workforce productivity analytics. The job will process events of employees productivity of the previous day, and store the performance of each employee in the Delta table "employees_performance". The table has the following schema:

"date DATE, employee_id STRING, rating DOUBLE"

The data engineering team wants data to be stored in the table with the ability to compare employees' performance across time.

Which of the following code blocks accomplishes this task?

### 選項
<!-- ⚠️ 保持英文原文，不要翻譯 -->
- **A.** `performance_df.write.mode("append").saveAsTable("employees_performance")`
- **B.** `performance_df.write.mode("overwrite").saveAsTable("employees_performance")`
- **C.** `performance_df.write.partitionBy("date").saveAsTable("employees_performance")`
- **D.** `performance_df.write.format("delta").saveAsTable("employees_performance")`

# 題目解析

## 📍 考點識別
**核心技術:** DataFrame write mode
**關鍵概念:** 資料累積、歷史比較
**題目關鍵字：**
- **nightly batch job**: 每晚批次作業
- **compare across time**: 跨時間比較
- **append**: 附加

---

## ✅ 正解說明
### 為什麼 A 是正確答案？

**`append` mode 會累積資料，保留歷史記錄**：
- 每次執行新增資料，不會覆蓋現有資料
- 歷史資料保留，可以跨時間比較
- 適合每日累積的分析場景

#### Write Mode 行為
```
append mode 行為：
Day 1: 寫入 2025-01-01 的資料 → 表格有 Day 1
Day 2: 寫入 2025-01-02 的資料 → 表格有 Day 1 + Day 2
Day 3: 寫入 2025-01-03 的資料 → 表格有 Day 1 + Day 2 + Day 3

結果：可以比較不同日期的 performance
```

#### 適用場景
```
nightly batch + 歷史比較 = append mode
├── 資料累積 → 歷史保留
├── 日期欄位 → 可過濾時間範圍
└── 跨時間比較 → 趨勢分析
```

---

## ❌ 錯誤選項排除

### B. mode("overwrite")
**為什麼錯誤？**
- **會覆蓋所有現有資料**
- 只保留最新批次的資料
- 無法進行跨時間比較

### C. partitionBy("date")
**為什麼錯誤？**
- **沒有指定 write mode**
- 預設模式是 `errorIfExists`
- 第二次執行會因表格已存在而失敗

### D. format("delta")
**為什麼錯誤？**
- **沒有指定 write mode**
- 同樣會使用預設的 `errorIfExists` 模式
- 且 `saveAsTable` 預設就是 Delta format

---

## 🧠 記憶法
### 口訣
**「歷史要保留，append 不會丟」**

### Write Mode 比較
| Mode | 行為 | 適用場景 |
|------|------|----------|
| append | 新增資料 | 累積歷史 |
| overwrite | 覆蓋資料 | 完全替換 |
| error | 報錯（預設） | 防止意外覆蓋 |
| ignore | 忽略 | 不重複寫入 |
