## 題目內容
### 題幹
<!-- ⚠️ 保持英文原文，不要翻譯 -->
A data engineer created a new table along with a comment using the following query:

```
CREATE TABLE payments
COMMENT "This table contains sensitive information"
AS SELECT * FROM bank_transactions
```

Which of the following commands allows the data engineer to review the comment of the table?
### 選項
<!-- ⚠️ 保持英文原文，不要翻譯 -->
- **A.** DESCRIBE EXTENDED payments
- **B.** SHOW COMMENTS payments
- **C.** SHOW TBLPROPERTIES payments
- **D.** DESCRIBE TABLE payments

# 題目解析

---

## 📍 考點識別
**核心技術:** Spark SQL 表註解查看
**關鍵概念:** `DESCRIBE EXTENDED` 會顯示表註解
**題目關鍵字：**
- **COMMENT**: 表註解
- **review the comment**: 查詢註解

---

## ✅ 正解說明
### 為什麼 A 是正確答案？
`DESCRIBE EXTENDED` 會顯示表的詳細資訊，包含表註解與欄位註解，因此可以查看 `COMMENT` 設定的內容。

---

## ❌ 錯誤選項排除
### B. SHOW COMMENTS
**為什麼錯誤？**
- Spark SQL 沒有 `SHOW COMMENTS` 指令。

### C. SHOW TBLPROPERTIES
**為什麼錯誤？**
- 表註解不是 table properties，通常不會在此顯示。

### D. DESCRIBE TABLE
**為什麼錯誤？**
- 不一定顯示表註解，需用 EXTENDED 才會看到。

---

|---|---|
