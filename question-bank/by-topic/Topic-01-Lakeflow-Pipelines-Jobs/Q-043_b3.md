## 題目內容
### 題幹
<!-- ⚠️ 保持英文原文，不要翻譯 -->
A data engineer defines the following function in their LDP pipeline:

```python
@dlt.table
@dlt.expect_or_drop("quantity_within_range", "quantity BETWEEN 0 AND 1000")
@dlt.expect_or_drop("recent_transaction", "transaction_date >= '2025-01-01'")
@dlt.expect_or_drop("valid_transaction", "transaction_id IS NOT NULL'")
def silver_sales():
    return dlt.read_stream("bronze_sales")
```

Which of the following correctly describes the result of running this pipeline?

### 選項
<!-- ⚠️ 保持英文原文，不要翻譯 -->
- **A.** Rows that violate the defined expectations are deleted from both tables.
- **B.** Rows that violate the defined expectations are deleted from the bronze_sales table.
- **C.** Rows that violate the defined expectations are filtered out, and only valid rows are written to silver_sales.
- **D.** Rows that violate the defined expectations are streamed into the silver_sales table.

# 題目解析

---

## 📍 考點識別
**核心技術:** DLT expect_or_drop 行為
**關鍵概念:** 資料品質規則、過濾機制
**題目關鍵字：**
- **expect_or_drop**: 期望或丟棄
- **filtered out**: 過濾掉
- **valid rows**: 有效的行

---

## ✅ 正解說明
### 為什麼 C 是正確答案？

**`expect_or_drop` 會過濾違規記錄，只寫入有效記錄**：
- 違規記錄被「丟棄」（不寫入目標表）
- 來源表（bronze_sales）不受影響
- 只有通過所有規則的記錄會進入 silver_sales

#### expect_or_drop 行為
```
expect_or_drop 處理流程：

bronze_sales (來源)
      │
      ▼
┌─────────────────┐
│ 檢查 Expectation │
│ 1. quantity     │
│ 2. transaction_date │
│ 3. transaction_id │
└─────────────────┘
      │
    ┌─┴─┐
 通過│   │失敗
    ▼   ▼
 寫入  丟棄
silver │
      │
      ▼
silver_sales (目標)
```

#### 重要概念
```
expect_or_drop 特性：
├── 來源不受影響 → bronze_sales 完整保留
├── 目標只有有效資料 → silver_sales 乾淨
├── 多個規則 → 必須全部通過
└── 指標記錄 → 違規數量可追蹤
```

---

## ❌ 錯誤選項排除

### A. 從兩個表都刪除
**為什麼錯誤？**
- **來源表（bronze_sales）不會被修改**
- DLT 不會回溯修改來源資料

### B. 從 bronze_sales 刪除
**為什麼錯誤？**
- **DLT 不會修改來源表**
- 資料品質規則只影響目標表

### D. 違規記錄會串流到 silver_sales
**為什麼錯誤？**
- **expect_or_drop 會丟棄違規記錄**
- 如果要保留違規記錄，應使用 expect（不帶 or_drop）

---

## 🧠 記憶法
### 口訣
**「or_drop 會丟棄，來源不動只改目標」**

### Expectation 類型比較
| 函數 | 違規記錄處理 | 來源影響 |
|------|-------------|----------|
| expect | 保留 | 無 |
| expect_or_drop | 丟棄 | 無 |
| expect_or_fail | Pipeline 失敗 | 無 |
