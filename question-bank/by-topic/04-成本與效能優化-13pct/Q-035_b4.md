# 題目解析

---

## 📍 考點識別
**核心技術:** Spark UI SQL Metrics
**關鍵概念:** 物理算子層級指標（spill size）
**題目關鍵字：**
- **SQL metrics**: 算子層級指標
- **query details page**: 詳細頁面

---

## ✅ 正解說明
### 為什麼 D 是正確答案？
Spark UI 的 SQL 詳細頁面會在每個物理算子上顯示 SQL metrics，例如 **spill size**（記憶體不足時溢寫磁碟的大小）。
