Which of the following is Not a valid Delta Lake File Statistics ?

# 題目解析

---

## 📍 考點識別
**核心技術:** Delta Lake file statistics
**關鍵概念:** 交易記錄中的統計欄位內容
**題目關鍵字：**
- **file statistics**: 檔案層級統計
- **first 32 columns**: 預設只收前 32 欄

---

## ✅ 正解說明
### 為什麼 C 是正確答案？
Delta Lake 的檔案統計包含**每檔案的總筆數、各欄位最小值、最大值與 null 計數**，但**不包含平均值**。因此「平均值」不是有效的 file statistics。

---

## ❌ 錯誤選項排除
### A / B / D
**為什麼錯誤？**
- 這些都是 Delta Lake 交易記錄中可見的檔案統計欄位。

---

## 🧠 記憶法
### 口訣
**「統計三兄弟：min、max、null，加上 count；沒有平均。」**

### 比較表
| 統計項目 | 是否包含 |
|---|---|
| numRecords | ✅ |
| minValues / maxValues | ✅ |
| nullCount | ✅ |
| avgValues | ❌ |
