# 題目解析

---

## 📍 考點識別
**核心技術:** Cluster 權限管理
**關鍵概念:** 最小權限原則
**題目關鍵字：**
- **minimal permissions**: 最小權限
- **start and terminate**: 啟動和終止
- **Can Restart**: 可重啟

---

## ✅ 正解說明
### 為什麼 D 是正確答案？

**「Can Restart」是啟動/終止 cluster 的最小權限**：
- 包含啟動和終止 cluster 的能力
- 不需要更高的 Can Manage 權限
- 不需要 cluster 創建權限

#### Cluster 權限層級
```
Cluster 權限層級（由低到高）：
├── No Permissions → 無法使用
├── Can Attach To → 可附加筆記本
├── Can Restart → 包含上述 + 啟動/終止
└── Can Manage → 包含上述 + 修改/刪除
```

#### Can Restart 能力
```
Can Restart 權限包含：
├── 附加筆記本和 Jobs
├── 檢視 Spark UI、日誌
├── 啟動 cluster
├── 終止 cluster
└── 重啟 cluster
```

---

## ❌ 錯誤選項排除

### A. "Can Attach To" privilege
**為什麼錯誤？**
- **權限不足**
- Can Attach To 只能附加筆記本
- 不能啟動或終止 cluster

### B. "Can Manage" privilege
**為什麼錯誤？**
- **權限過高**
- Can Manage 包含修改和刪除 cluster
- 超過啟動/終止所需

### C. Cluster creation + Can Restart
**為什麼錯誤？**
- **不需要 cluster 創建權限**
- 題目說的是「existing cluster」（現有 cluster）
- 創建權限與操作現有 cluster 無關

---

## 🧠 記憶法
### 口訣
**「啟動終止用 Restart，不用 Manage 也不用創建」**

### Cluster 權限對照
| 操作 | 最小權限 |
|------|----------|
| 附加筆記本 | Can Attach To |
| 啟動/終止 | Can Restart |
| 修改設定 | Can Manage |
| 創建新 cluster | Allow cluster creation |
