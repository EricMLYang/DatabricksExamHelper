# 題目解析

---

## 📍 考點識別
**核心技術:** Materialized View
**關鍵概念:** 預計算、物理儲存、自動更新
**題目關鍵字：**
- **physically stores**: 物理儲存
- **precomputed query results**: 預計算查詢結果
- **automatically or on a schedule**: 自動或排程更新

---

## ✅ 正解說明
### 為什麼 D 是正確答案？

**Materialized View 符合所有描述特徵**：
- 物理儲存查詢結果（不是每次執行查詢）
- 自動或排程更新
- 優化複雜聚合和 BI 工作負載

#### Materialized View 特性
```
Materialized View 特性：
├── 物理儲存 → 結果存在 Delta 表中
├── 預計算 → 查詢時直接讀取結果
├── 自動更新 → 來源資料變更時更新
├── 排程更新 → 可設定更新頻率
└── 效能優化 → 減少重複計算
```

#### 適用場景
```
適合 Materialized View 的場景：
├── 複雜聚合查詢（SUM, AVG, COUNT）
├── BI Dashboard 資料
├── 報表資料
└── 經常查詢但不常變更的資料
```

---

## ❌ 錯誤選項排除

### A. Standard view
**為什麼錯誤？**
- **不物理儲存資料**
- 只是保存的查詢定義
- 每次查詢都重新計算

### B. Temporary view
**為什麼錯誤？**
- **只存在於 session 中**
- 不持久化
- session 結束即消失

### C. Streaming table
**為什麼錯誤？**
- **用於增量資料攝取，不是預計算結果**
- 處理串流資料
- 不是為了聚合優化設計

### View 類型比較
| 類型 | 物理儲存 | 持久性 | 更新方式 |
|------|----------|--------|----------|
| Standard View | 否 | 持久 | 即時計算 |
| Temporary View | 否 | Session | 即時計算 |
| Materialized View | 是 | 持久 | 自動/排程 |
