## 題目內容
### 題幹
<!-- ⚠️ 保持英文原文，不要翻譯 -->
A data engineering team created a new workspace, which is automatically enabled for Unity Catalog. They observed that it contains a default workspace catalog and a default schema.

Which of the following statements correctly describes the default privileges that workspace users have on this catalog and schema?
### 選項
<!-- ⚠️ 保持英文原文，不要翻譯 -->
- **A.** Workspace users have `ALL PRIVILEGES` on the default schema, along with `USE CATALOG` on the workspace catalog.
- **B.** Workspace users primarily have `CREATE TABLE`, `CREATE VOLUME`, `CREATE FUNCTION`, and `USE SCHEMA` privileges on the default schema, along with `USE CATALOG` on the workspace catalog.
- **C.** Workspace users do not have any privileges on the default schema by default, unless the workspace administrator explicitly grants them the necessary permissions.
- **D.** Workspace users have `ALL PRIVILEGES` on the workspace catalog.

# 題目解析

---

## 📍 考點識別
**核心技術:** Unity Catalog 預設 catalog/schema 權限
**關鍵概念:** `USE CATALOG` + 預設 schema 的建立/使用權限
**題目關鍵字：**
- **default workspace catalog**: 系統建立的預設 catalog
- **default schema**: 預設 schema 權限配置

---

## ✅ 正解說明
### 為什麼 B 是正確答案？
新 workspace 啟用 Unity Catalog 後，會建立預設 catalog 與 schema。一般使用者會有 **`USE CATALOG`** 權限，以及在預設 schema 上的常用建立權限（如 `CREATE TABLE`、`CREATE VOLUME`、`CREATE FUNCTION`、`USE SCHEMA` 等），以便進行基本資料工程工作。

---

## ❌ 錯誤選項排除
### A / D
**為什麼錯誤？**
- 預設不會給到 `ALL PRIVILEGES`。

### C
**為什麼錯誤？**
- 預設會提供基本使用與建立權限，不是完全沒有權限。

---

## 🧠 記憶法
### 口訣
**「預設可用可建表，不是全權。」**

### 比較表
| 物件 | 預設權限 |
|---|---|
| Workspace catalog | `USE CATALOG` |
| Default schema | `USE SCHEMA` + 常用 CREATE 權限 |
