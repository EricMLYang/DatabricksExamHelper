## 題目內容
### 題幹
<!-- ⚠️ 保持英文原文，不要翻譯 -->
A data engineer has heard recently that users who have access to Databricks Secrets could be able to display the values of secrets in notebooks.

Which of the following could be a workaround to print the value of a Databricks secret in plain text?

### 選項
<!-- ⚠️ 保持英文原文，不要翻譯 -->
- **A.**
```python
db_password = dbutils.secrets.get("prod-scope", "db-password", redacted=False)
print(db_password)
```
- **B.**
```python
db_password = dbutils.secrets.get("prod-scope", "db-password")
display(db_password)
```
- **C.**
```python
db_password = dbutils.secrets.get("prod-scope", "db-password")
print(db_password, redacted=False)
```
- **D.**
```python
db_password = dbutils.secrets.get("prod-scope", "db-password")
for char in db_password:
    print(char)
```

## 📍 考點識別
**核心技術:** Databricks Secrets 遮罩機制
**關鍵概念:** Secret Redaction、繞過遮罩的方式
**題目關鍵字：**
- **display the values of secrets**: 顯示密鑰值
- **workaround**: 繞過方法
- **print in plain text**: 以明文列印

---

## ✅ 正解說明
### 為什麼 D 是正確答案？

**Databricks 的遮罩機制是字串匹配**：
- 當輸出**完整**的密鑰字串時會被遮罩
- 逐字元列印時，每個字元不會被識別為密鑰
- 這是已知的繞過方式（但不建議使用）

#### Secret Redaction 原理
```
遮罩機制：
├── 偵測輸出中的完整密鑰字串
├── 匹配成功 → 替換為 [REDACTED]
└── 逐字元 → 無法匹配完整字串
```

#### 繞過原理圖解
```python
# 假設密鑰值為 "MyPass123"

# 正常列印 → 被遮罩
print(secret)  # 輸出: [REDACTED]

# 逐字元列印 → 繞過遮罩
for char in secret:
    print(char)
# 輸出:
# M
# y
# P
# a
# s
# s
# 1
# 2
# 3
```

#### 為什麼這能繞過？
```
遮罩檢測機制：
├── 檢查輸出字串是否 == 完整密鑰
├── "MyPass123" → 匹配 → [REDACTED]
├── "M" → 不匹配 → 正常顯示
├── "y" → 不匹配 → 正常顯示
└── 每個單字元都不會觸發遮罩
```

## ❌ 錯誤選項排除

### A. dbutils.secrets.get(..., redacted=False)
**為什麼錯誤？**
- **`redacted` 參數不存在**
- `dbutils.secrets.get()` 只接受 scope 和 key 兩個參數
- 這是虛構的語法

```python
# 正確語法
dbutils.secrets.get(scope, key)

# 錯誤語法 - 沒有 redacted 參數
dbutils.secrets.get(scope, key, redacted=False)  # TypeError!
```

### B. display(db_password)
**為什麼錯誤？**
- **`display()` 同樣會觸發遮罩**
- 遮罩機制在所有輸出函數中都有效
- 不論用 `print()` 還是 `display()` 都會被遮罩

```python
secret = dbutils.secrets.get("scope", "key")
display(secret)  # 輸出: [REDACTED]
print(secret)    # 輸出: [REDACTED]
```

### C. print(db_password, redacted=False)
**為什麼錯誤？**
- **`print()` 沒有 `redacted` 參數**
- 遮罩是 Databricks 層級的功能，不是 Python print 的參數
- 這是虛構的語法

```python
# Python print 的合法參數
print(*objects, sep=' ', end='\n', file=sys.stdout, flush=False)

# redacted 不是合法參數
print(secret, redacted=False)  # TypeError!
```

### 常見 Secret 操作
| 操作 | 結果 |
|------|------|
| `print(secret)` | [REDACTED] |
| `display(secret)` | [REDACTED] |
| `spark.conf.set("key", secret)` | 值被遮罩 |
| `for c in secret: print(c)` | 明文顯示 |

