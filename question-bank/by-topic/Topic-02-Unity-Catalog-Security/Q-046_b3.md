# 題目解析

---

## 📍 考點識別
**核心技術:** Cluster 權限管理
**關鍵概念:** 最小權限原則
**題目關鍵字：**
- **minimal permissions**: 最小權限
- **attach a notebook**: 附加筆記本
- **Can Attach To**: 可附加到

---

## ✅ 正解說明
### 為什麼 C 是正確答案？

**「Can Attach To」是附加筆記本的最小權限**：
- 只需要 Can Attach To 即可將筆記本連接到 cluster
- 不需要更高的權限（如 Can Restart 或 Can Manage）
- 不需要 cluster 創建權限

#### Cluster 權限層級
```
Cluster 權限層級（由低到高）：
├── No Permissions → 無法使用
├── Can Attach To → 可附加筆記本、jobs
├── Can Restart → 包含上述 + 啟動/終止 cluster
└── Can Manage → 包含上述 + 修改/刪除 cluster
```

#### 權限能力對照表
```
能力                        | Attach To | Restart | Manage
---------------------------|-----------|---------|--------
附加筆記本/Job              | ✅        | ✅      | ✅
檢視 Spark UI              | ✅        | ✅      | ✅
啟動/終止 cluster          | ❌        | ✅      | ✅
修改 cluster 設定          | ❌        | ❌      | ✅
刪除 cluster               | ❌        | ❌      | ✅
```

---

## ❌ 錯誤選項排除

### A. "Can Manage" privilege
**為什麼錯誤？**
- **權限過高**
- Can Manage 是最高權限，遠超過附加筆記本所需

### B. "Can Restart" privilege
**為什麼錯誤？**
- **權限過高**
- Can Restart 包含啟動/終止功能，超過所需

### D. Cluster creation + Can Attach To
**為什麼錯誤？**
- **不需要 cluster 創建權限**
- 題目說的是「existing cluster」（現有 cluster）
- 創建權限與附加到現有 cluster 無關

---

## 🧠 記憶法
### 口訣
**「附加用 Attach，重啟用 Restart，管理用 Manage」**

### 權限最小化原則
| 操作 | 最小權限 |
|------|----------|
| 附加筆記本 | Can Attach To |
| 啟動/終止 | Can Restart |
| 修改設定 | Can Manage |
