## ✅ 正解說明
### 為什麼 A 是正確答案？

**`%pip install` 是 Databricks 標準的套件安裝方式**：
- 作用範圍限於當前 Notebook Session
- 同一 Job 的其他 Notebook 也可存取
- 不影響其他 Notebook 或 Cluster

#### %pip install 特性
```
%pip install 行為：
├── 作用範圍 → 當前 Notebook Session
├── 持續性 → Session 結束後消失
├── 隔離性 → 不影響其他 Notebook
└── 相容性 → 支援所有 pip 語法
```

#### 使用範例
```python
# 安裝本地 wheel 檔案
%pip install my_package.whl

# 安裝 PyPI 套件
%pip install pandas==2.0.0

# 安裝多個套件
%pip install numpy scipy matplotlib

# 從 requirements.txt 安裝
%pip install -r requirements.txt
```

#### Notebook-scoped Libraries 優勢
```
為什麼使用 Notebook-scoped Libraries？
├── 隔離性 → 不同 Notebook 可用不同版本
├── 彈性 → 無需重啟 Cluster
├── 安全性 → 不影響其他使用者
└── 測試便利 → 快速嘗試新套件
```

## ❌ 錯誤選項排除

### B. %fs install my_package.whl
**為什麼錯誤？**
- **`%fs` 是檔案系統操作，不是套件安裝**
- %fs 用於 ls、cp、rm 等檔案操作
- 沒有 install 功能

```python
# %fs 的正確用法
%fs ls /path/to/directory
%fs cp /source /destination
%fs rm /path/to/file

# %fs 沒有 install 命令
%fs install ...  # 錯誤！
```

### C. %whl install my_package
**為什麼錯誤？**
- **`%whl` 不是有效的 Magic Command**
- Databricks 沒有這個命令
- 這是虛構的語法

```
Databricks 有效的 Magic Commands：
├── %python, %scala, %sql, %r → 語言切換
├── %pip → Python 套件管理
├── %fs → 檔案系統操作
├── %sh → Shell 命令
└── 沒有 %whl
```

### D. %python install my_package.whl
**為什麼錯誤？**
- **`%python` 用於切換語言，不是安裝套件**
- %python 後面應該是 Python 程式碼
- install 不是 Python 關鍵字

```python
# %python 的正確用法（在非 Python notebook 中）
%python
print("Hello from Python")

# 這不是有效的 Python 語法
%python install my_package.whl  # 錯誤！
```

## 🧠 記憶法
### 口訣
**「安裝套件用 %pip，Session 範圍不影響」**

### Databricks Magic Commands 總覽
| Command | 用途 | 範例 |
|---------|------|------|
| `%pip` | Python 套件管理 | `%pip install pandas` |
| `%fs` | 檔案系統操作 | `%fs ls /data` |
| `%sh` | Shell 命令 | `%sh pwd` |
| `%sql` | 執行 SQL | `%sql SELECT * FROM table` |
| `%python` | 切換到 Python | `%python print(1)` |

### Library 安裝方式比較
| 方式 | 範圍 | 持續性 | 需重啟 Cluster |
|------|------|--------|---------------|
| `%pip install` | Notebook | Session 內 | 否 |
| Cluster Library | Cluster | 永久 | 是 |
| Init Script | Cluster | 永久 | 是 |

### 常用 %pip 操作
```python
# 安裝套件
%pip install package_name

# 安裝特定版本
%pip install package_name==1.2.3

# 升級套件
%pip install --upgrade package_name

# 列出已安裝套件
%pip list

# 顯示套件資訊
%pip show package_name
```
