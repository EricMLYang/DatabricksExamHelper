## ✅ 正解說明
### 為什麼 B 是正確答案？

**Python Wheel 是一種二進位套件發行格式**：
- 副檔名為 `.whl`
- 是 ZIP 格式的壓縮檔
- 用於快速安裝 Python 套件

#### Wheel 檔案結構
```
my_package-1.0.0-py3-none-any.whl (ZIP 格式)
├── my_package/
│   ├── __init__.py
│   ├── module1.py
│   └── module2.py
├── my_package-1.0.0.dist-info/
│   ├── METADATA
│   ├── WHEEL
│   ├── RECORD
│   └── top_level.txt
```

#### Wheel 命名規範
```
{distribution}-{version}(-{build tag})?-{python}-{abi}-{platform}.whl

範例：
numpy-1.24.0-cp311-cp311-manylinux1_x86_64.whl
├── numpy → 套件名稱
├── 1.24.0 → 版本
├── cp311 → Python 版本
├── cp311 → ABI
└── manylinux1_x86_64 → 平台
```

#### 為什麼使用 Wheel？
```
Wheel 的優勢：
├── 快速安裝 → 不需編譯
├── 一致性 → 預先編譯的二進位
├── 可靠性 → 固定的依賴關係
└── 便利性 → 易於分發和部署
```

#### 在 Databricks 使用 Wheel
```python
# 安裝 Wheel 檔案
%pip install my_package-1.0.0-py3-none-any.whl

# 或透過 dbfs 路徑
%pip install /dbfs/path/to/my_package.whl

# 使用安裝的套件
import my_package
```

## ❌ 錯誤選項排除

### A. Wheel 是 repository
**為什麼錯誤？**
- **Repository（倉庫）是 PyPI、Artifactory 等**
- Wheel 是套件格式，不是倉庫
- 兩者是不同概念

```
概念區分：
├── Repository → 儲存和托管套件的地方（如 PyPI）
├── Wheel → 套件的檔案格式（.whl）
└── pip → 安裝套件的工具
```

### C. Wheel 是 pip 的替代品
**為什麼錯誤？**
- **pip 是安裝工具，Wheel 是檔案格式**
- pip 用來安裝 Wheel 檔案
- 兩者是互補關係，不是替代

```
pip 與 Wheel 關係：
pip install package.whl
    │           │
    └─ 安裝工具  └─ 檔案格式

pip 可以安裝：
├── Wheel (.whl)
├── Source Distribution (.tar.gz)
└── 直接從 PyPI 安裝
```

### D. Wheel 是 virtual environment
**為什麼錯誤？**
- **Virtual Environment 是隔離環境（如 venv、conda）**
- Wheel 是套件格式
- 兩者功能完全不同

```
概念區分：
├── Virtual Environment → 隔離的 Python 環境
├── Wheel → 套件發行格式
└── 兩者無關
```

## 🧠 記憶法
### 口訣
**「Wheel 是輪子，載著套件快速跑」**

### Python 套件相關概念
| 概念 | 說明 | 範例 |
|------|------|------|
| Wheel | 二進位套件格式 | `.whl` 檔案 |
| pip | 套件安裝工具 | `pip install` |
| PyPI | 套件倉庫 | pypi.org |
| venv | 虛擬環境 | `python -m venv` |

### Wheel vs Source Distribution
| 特性 | Wheel (.whl) | Source (.tar.gz) |
|------|-------------|------------------|
| 編譯 | 預先編譯 | 需要編譯 |
| 安裝速度 | 快 | 慢 |
| 平台依賴 | 可能有 | 無 |
| 檔案大小 | 較大 | 較小 |

### 建立 Wheel 檔案
```bash
# 建立 Wheel
python setup.py bdist_wheel

# 或使用 build
python -m build --wheel

# 產出位置
dist/my_package-1.0.0-py3-none-any.whl
```
