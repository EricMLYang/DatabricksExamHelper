## 📊 Structured Streaming 串流處理

### 觸發模式 (Trigger)
- **[b2-Q003]** 預設 trigger：**500 毫秒** (無指定時)
- **[b1-Q005]** `trigger(availableNow=True)`：批次處理增量資料最佳模式
- **[b4-Q029]** `trigger(processingTime="2 minutes")`：每 2 分鐘執行一次 micro-batch

### 視窗函數 (Window)
- **[b1-Q008]** `window(時間欄位, '視窗大小', '滑動間隔', 'offset')`
  - 範例：`window(event_time, '10 minutes', '10 minutes', '3 minutes')`
  - 第三參數 = 視窗大小 → 非重疊視窗 (tumbling)
  - offset → 視窗起始點偏移

### 串流限制
- **[b1-Q017]** 不支援非時間基礎的視窗函數：`rank()`, `row_number()`, `dense_rank()`

### Join 行為
- **[b1-Q046]** Stream-Stream Join：Spark 會 buffer 雙方的歷史輸入作為 state

## 🗄️ Delta Lake 特性

### Change Data Feed (CDF)
- **[b1-Q001]** CDF + AUTO CDC：`APPLY CHANGES INTO` 傳播所有變更
- **[b2-Q007]** CDF 資料存放：`_change_data` 資料夾
- **[b2-Q017]** `_change_data` 與主要資料檔案遵循相同保留政策，`VACUUM` 會一併刪除

### Clone 複製
- **[b1-Q010]** Deep Clone：`CREATE OR REPLACE TABLE target DEEP CLONE source`
- **[b2-Q018]** Shallow Clone：只複製 transaction log，VACUUM 來源表會導致 files not found
- **[b1-Q026]** CTAS：建立資料複本，無依賴關係

### 表格屬性
- **[b4-Q009]** `delta.appendOnly = true`：**禁止 UPDATE/DELETE**，允許 INSERT
- **[b2-Q016]** 刪除檔案保留期：`delta.deletedFileRetentionDuration = 'interval 30 days'`

### Auto Compaction
- **[b1-Q016]** 觸發時機：寫入後自動；不支援 Z-Ordering；目標檔案大小 **128 MB**

### Deletion Vectors
- **[b2-Q010]** 元資料結構，追蹤邏輯刪除的列，不重寫檔案

## 🔐 權限與安全 (Unity Catalog)

### Row Filter / Column Mask
- **[b2-Q029]** Row Filter：`ALTER TABLE <table> SET ROW FILTER <function> ON (<columns>)`
- **[b4-Q028]** Column Mask：`ALTER TABLE <table> ALTER COLUMN <col> SET MASK <function>`
- **[b1-Q042]** Row Filter 邏輯：
  ```sql
  CREATE FUNCTION us_filter(region STRING)
  RETURN IF(IS_ACCOUNT_GROUP_MEMBER('finance_team'), true, region='US');
  ```
- **[b4-Q006]** 條件語法：`WHEN is_member("group") THEN TRUE`

### Secrets 權限
- **[b4-Q008]** 可讀 secrets：Workspace Admin、Secret Creator、READ/MANAGE 權限
- **[b3-Q047]** 權限設定在 **scope 層級**，非個別 secret

### Delta Sharing
- **[b1-Q029]** 分享歷史版本：`ALTER SHARE <share> ADD TABLE <table> WITH HISTORY`
- **[b2-Q011]** 三種存取模式：WITH HISTORY、Temporary credentials、Direct storage access

## 📝 語法細節 & 陷阱

### Tags 標籤
- **[b1-Q002]** ⚠️ `ALTER TABLE ... SET TBLPROPERTIES` (複數) vs `SET TAG` (單數)

### SQL 函數
- **[b1-Q004]** `distinct()`：無參數，過濾「整行完全相同」資料
- **[b1-Q024]** 查看表格詳細資訊：`DESCRIBE EXTENDED <table>`
- **[b1-Q045]** `sha2()` 支援位元長度：**0** (=256), **224**, **256**, **384**, **512**
- **[b4-Q036]** 查看新增資料：`SELECT * FROM table EXCEPT SELECT * FROM table@v{current_version-1}`
- **[b4-Q042]** CASE 條件：
  ```sql
  SELECT CASE WHEN new > 200 AND processing > 150 THEN 1 ELSE 0 END
  FROM (SELECT SUM(CASE WHEN ...) AS new, ... FROM tickets) statistics
  ```

### Notebook 語法
- **[b4-Q011]** Notebook 標記：`# Databricks notebook source`

### Spark 讀取選項
- **[b1-Q013]** 錯誤資料路徑：`.option("badRecordsPath", "s3://project/quarantine")`
- **[b2-Q020]** foreachBatch：`microBatchDF.sparkSession.sql(sql_query)` (在 Executor 取 session)
- **[b4-Q012]** 忽略刪除：`.option("ignoreDeletes", True)`
- **[b4-Q039]** Schema 演進：`.option("cloudFiles.schemaEvolutionMode", "addNewColumns")`
- **[b2-Q023]** Rescue 模式：Schema 不演進、新欄位放 `_rescued_data`、串流不失敗
- **[b3-Q058]** `spark.read` 靜態讀取 + `startingVersion: 0`：每次從版本 0 讀到最新

### AI 功能
- **[b1-Q034]** Unity Catalog Explorer：AI-generated column comments

### 統計資訊
- **[b3-Q039]** 高基數欄位統計效用有限；Nested fields 不計入前 32 欄位

## 💡 快速記憶法

### 數字記憶
- **500** 毫秒 = 預設 trigger
- **128** MB = Auto Compaction 目標大小
- **30** 天 = 預設 deletedFileRetentionDuration

### 語法模式
- `ALTER TABLE ... SET` → 單複數要對應 (TAG vs TBLPROPERTIES)
- `window(欄位, 大小, 滑動, offset)` → 大小=滑動 則為 tumbling window
- `EXPECT ... ON VIOLATION` → DLT 資料品質

### 概念對比
- **Deep Clone** (複製資料) vs **Shallow Clone** (複製 log)
- **appendOnly** (禁止修改) vs **disableUpdate** (不存在的屬性)
- **Integration Test** (模組間) vs **E2E Test** (整個系統)
