# Databricks Exam Helper

Databricks Data Engineer Associate 準備用的題庫與筆記整理專案。

## 專案內容

- 題目解析與練習題庫（依版本、依主題）
- 核心觀念速記與考點地圖
- 練習工具與模板

## 目錄說明

- `question-bank/`：題目與解析
- `docs/`：考點地圖、核心知識、經驗整理
- `practice_exam/`：互動練習與模擬題
- `tooling/`：標籤規範與貢獻輔助文件
- `tests/`：內容處理工具的測試

## 建議使用流程

1. 先看考點總覽：[docs/exam-map/exam-plan.md](docs/exam-map/exam-plan.md)
2. 依序練習：`question-bank/by-order_b4/` 或 `question-bank/by-order_v1/`
3. 針對弱點補強：`question-bank/by-topic/` + `docs/core-knowledge/`
4. 考前用 `practice_exam/` 做限時模擬
